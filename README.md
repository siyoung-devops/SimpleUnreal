# PocketUnreal

언리얼 UObject 시스템의 리플렉션, RPC, GC를 C++20으로 구현한 프로젝트입니다.

## 📌 프로젝트 소개

언리얼에서는 멤버에 `UPROPERTY`, `UFUNCTION`만 붙이면 에디터 노출, 함수 호출, 메모리 해제를 엔진이 처리해 줍니다.
매크로 뒤에서 이 기능들이 어떤 구조로 동작하는지 이해하고 싶어서, 핵심 구조만 골라 만들어 보았습니다.
목표는 오브젝트 10만 개에서 GC 한 번에 멈추는 시간을 10ms 안으로 만드는 것이었습니다.

## 🛠 구현 내용

- **리플렉션** : 빌드 전에 `HeaderParser`가 헤더의 `UPROPERTY`, `UFUNCTION`을 읽어 등록 코드 `Generated.cpp`를 만듭니다. 클래스마다 `UClass`에 멤버의 이름, 오프셋, 타입을 담아 실행 중에 값을 읽고 씁니다.
- **RPC** : `"AddAge 5"` 같은 문자열 명령을 받아, 같은 이름으로 등록된 멤버 함수를 찾고 인자를 타입에 맞게 바꿔 호출합니다.
- **GC** : 루트에서 출발해 참조를 따라가며 표시(Mark)하고, 표시가 없는 오브젝트를 지웁니다(Sweep). 참조 위치는 리플렉션 등록 때 `UClass`에 함께 저장해 둡니다.

## 📊 GC 측정 결과

오브젝트 10만 개를 만든 8가지 상황에서 GC 한 번의 시간을 30회 측정했습니다. 단위는 ms입니다.

| 상황 | 내용 | 평균 | 최대 |
| --- | --- | ---: | ---: |
| AllAlive | 루트 회사가 직원 99,999명을 참조, 모두 생존 | 2.44 | 3.27 |
| AllDead | 같은 구성에서 루트 해제, 모두 삭제 | 3.39 | 7.88 |
| Random | 직원을 루트 회사와 일반 회사에 무작위로 나눔 | 3.57 | 4.84 |
| Half | 직원 절반은 루트 회사, 절반은 일반 회사 | 3.37 | 5.96 |
| Chain | 회사 10만 개가 한 줄로 이어짐 | 4.84 | 5.47 |
| Hierarchy | 루트 회사 → 자회사 → 손자회사 구조에서 자회사 하나를 끊음 | 2.16 | 2.92 |
| Cycle | 서로 참조하는 회사 쌍 5만 개, 루트 없음 | 6.07 | 7.30 |
| Ring | Chain의 마지막 회사가 처음 회사를 다시 참조 | 4.91 | 5.61 |

8가지 상황 모두 30회 중 가장 오래 걸린 값이 10ms 안이었습니다.

## ⚙ 개발 환경

- Visual Studio 2026, C++20, Windows x64
- `PocketUnreal.slnx`를 열고 `Release | x64`로 빌드하면, `HeaderParser.exe`가 먼저 실행되어 `Generated.cpp`를 새로 만듭니다.
